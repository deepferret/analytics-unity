# PRD: Phase 1 Sprint 3B — Unity SDK (com.dataferret.analytics)

## 1. 개요

### 1.1 목적

Unity 게임 스튜디오를 위한 네이티브 분석 SDK C# 패키지(`com.dataferret.analytics`)를 구현한다.
게임은 이벤트 기반 분석이 핵심이다 — 플레이어 행동 퍼널, 리텐션 측정, 인앱 결제 추적, A/B 테스트가 게임 비즈니스를 좌우한다.
기존 솔루션(Unity Analytics, GameAnalytics)은 범용 분석 플랫폼과 분리되어 있어 커스텀 분석이 어렵다.

**문제**: 게임 스튜디오는 이벤트 수집 SDK와 분석 플랫폼이 별개여서 데이터를 이중으로 관리해야 한다.
비기술 담당자가 게임 이벤트를 자유롭게 쿼리하거나 AI 기반 자동 분석을 활용하기 어렵다.

**해결**: Unity SDK가 이벤트를 수집하여 DataFerret Collector API로 전송하면, 기존 AI Chat, 대시보드, 이상 탐지 기능을 즉시 활용할 수 있다.
"게임 이벤트 수집 → AI 기반 자동 분석"을 하나의 플랫폼에서 제공하는 솔루션이 된다.

**4가지 핵심 제공 가치**:
- **멀티플랫폼 단일 SDK**: Unity 하나로 Android, iOS, WebGL, Windows, macOS, Linux 모두 커버
- **게임 도메인 특화 자동 수집**: 세션, 씬 전환, 에러, 성능 샘플 자동 추적
- **GC Allocation 최적화**: 게임 런타임 성능을 해치지 않도록 Track() 1회 < 1KB GC Alloc 목표
- **UPM 배포**: Unity Package Manager(Git URL) + OpenUPM 레지스트리로 5분 내 설치 가능

**CookApps 전략적 포지셔닝**: CookApps의 게임 도메인 노하우를 활용하여 게임 분석 시장에서
차별화된 진입점 확보. 자사 게임에도 즉시 적용 가능.

**관련 기획서**: `docs/plans/data-pipeline/001_sdk_design.md` (Section 5), `docs/plans/data-pipeline/009_implementation_roadmap.md`

### 1.2 현재 상태

#### 이미 구현된 것

- **Collector API**: `apps/backend/src/collector/` — POST /v1/collect/batch 엔드포인트, Write Key 인증
- **Write Key 시스템**: `ApiKeyService` 확장 — `event:write` 권한, `wk_` 접두사 지원
- **PostgreSQL 큐**: `raw_events` 테이블 — 수집 버퍼 (7일 TTL), 중복 제거 (UNIQUE constraint)
- **배치 프로세서**: 5분 Cron → raw_events → Parquet 변환 → S3 업로드
- **EventEnvelope 규격**: `context.game` 객체 포함, Unity SDK Context 처리 로직 Collector에 반영
- **이벤트 브라우저**: library.name으로 SDK 타입 필터 지원 (Unity SDK 이벤트 구분 가능)

#### 없는 것

- Unity C# SDK 패키지 (`com.dataferret.analytics`) — 코드 전무
- UPM 배포 설정 (package.json, .asmdef 파일, Git 레포지토리)
- Editor 통합 (DataFerretEditorWindow, BuildProcessor)
- WebGL JavaScript Bridge (.jslib 파일)
- 크로스플랫폼 빌드 검증 (Android/iOS/WebGL/PC)
- Unity Test Framework 기반 테스트 (EditMode + PlayMode)
- OpenUPM 레지스트리 등록

### 1.3 기술 스택

- **언어**: C# (.NET Standard 2.1, Unity 2021.3 LTS 이상)
- **직렬화**: Newtonsoft.Json for Unity (`com.unity.nuget.newtonsoft-json` 3.2.1)

- **MonoBehaviour**: FlushScheduler — DontDestroyOnLoad 싱글톤
- **테스팅**: NUnit (Unity Test Framework), EditMode + PlayMode 양쪽 지원
- **에디터**: UnityEditor API (EditorWindow, IPreprocessBuild)
- **배포**: UPM (Unity Package Manager) Git URL + OpenUPM 레지스트리

### 2.2 아키텍처 다이어그램

```
Game Code (MonoBehaviour)
    │
    ▼
DataFerretAnalytics (static facade)
    │
    ├─ EventBuilder.BuildTrack() / BuildIdentify() / BuildScreen() / BuildGroup()
    │       └─ EventEnvelope 생성 (eventId=UUID v7, timestamp, context 자동 수집)
    │
    ▼
EventQueue (ConcurrentQueue<EventEnvelope>)
    │   • MaxQueueSize = 1000 (초과 시 oldest drop)
    │   • Thread-safe 읽기/쓰기
    │
    ▼
FlushScheduler (MonoBehaviour, DontDestroyOnLoad)
    │   • Update() 루프: flushInterval 경과 시 flush
    │   • OnApplicationPause(true): 즉시 flush
    │   • OnApplicationQuit(): 동기 flush
    │
    ├─ [Normal] UnityWebRequestTransport (Coroutine)
    │       └─ POST /v1/collect/batch
    │           Authorization: Bearer {writeKey}
    │           Retry: 지수 백오프 (1s → 2s → 4s), max 3회
    │
    └─ [WebGL] WebGLTransport (.jslib bridge)
            └─ JavaScript fetch() / sendBeacon()
                (브라우저 네이티브 HTTP, CORS 준수)

전송 실패 시:
    └─ FilePersistence: .jsonl 파일에 append
           저장 경로: Application.persistentDataPath/dataferret/
           최대 크기: 5MB
    └─ WebGLPersistence: PlayerPrefs fallback (WebGL, 1MB 제한)

다음 Init() 시:
    └─ FilePersistence.Load() → queue에 merge → 재전송
```

**자동 수집 흐름**:
```
SessionTracker
    OnApplicationPause(false) / Init() → track('session_start')
    OnApplicationPause(true) + 30분 경과 / OnApplicationQuit() → track('session_end')

SceneTracker
    SceneManager.sceneLoaded → screen(sceneName, { previous_scene, load_time })

LifecycleTracker
    OnApplicationPause(true)  → track('app_backgrounded')
    OnApplicationPause(false) → track('app_foregrounded')

ErrorTracker
    Application.logMessageReceived (LogType.Exception / Error)
    → track('error_occurred', { message, stackTrace(1000자), logType })
    동일 메시지 60초 내 dedup 처리

PerformanceTracker (opt-in)
    InvokeRepeating 30초 → track('performance_sample', { fps, memory_used, mono_heap })
```

### 2.3 플랫폼별 구현 차이

| 기능 | Android / iOS / PC | WebGL |
|------|--------------------|-------|
| HTTP 전송 | `UnityWebRequest` (코루틴) | `.jslib` → `fetch()` / `sendBeacon()` |
| 오프라인 큐 영속화 | `.jsonl` 파일 (`Application.persistentDataPath`) | `PlayerPrefs` (1MB 제한) |
| 백그라운드 스레드 | 가능 (System.Threading) | 불가 (메인 스레드 전용) |
| CORS | 해당 없음 (브라우저 아님) | 필수 (Write Key allowedOrigins 등록) |
| 파일 시스템 | `System.IO.File` 직접 사용 | 미지원 (IndexedDB는 Phase 2) |
| 앱 종료 감지 | `OnApplicationQuit()` | `visibilitychange` → `sendBeacon` |

## 4. 이벤트 큐 (C#)

### 4.1 EventQueue — ConcurrentQueue 래퍼

```csharp
public class EventQueue
{
    private readonly ConcurrentQueue<EventEnvelope> _queue;
    private readonly int _maxSize;

    public EventQueue(int maxSize = 1000)
    {
        _queue = new ConcurrentQueue<EventEnvelope>();
        _maxSize = maxSize;
    }

    public void Enqueue(EventEnvelope envelope)
    {
        // 최대 크기 초과 시 oldest drop
        while (_queue.Count >= _maxSize)
        {
            _queue.TryDequeue(out _);
            if (DataFerretAnalytics.Config?.Debug == true)
            {
                UnityEngine.Debug.LogWarning("[DataFerret] Queue full, dropping oldest event.");
            }
        }
        _queue.Enqueue(envelope);
    }

    // 최대 batchSize 건 디큐 (한 번의 flush에 최대 500건)
    public List<EventEnvelope> DequeueBatch(int batchSize = 500)
    {
        var batch = new List<EventEnvelope>(batchSize);
        while (batch.Count < batchSize && _queue.TryDequeue(out var item))
        {
            batch.Add(item);
        }
        return batch;
    }

    public int Count => _queue.Count;
    public bool IsEmpty => _queue.IsEmpty;
}
```

**설계 원칙**:
- 스레드 안전: `ConcurrentQueue<T>` 사용 (Enqueue는 게임 메인 스레드, Dequeue는 플러시 타이밍)
- 최대 크기 1000건 (설정으로 변경 가능)
- 초과 시 가장 오래된 이벤트 drop + 경고 로그 (Debug 모드)
- 한 번의 flush에 최대 500건 (배치 요청 크기 제한 대응)

### 4.2 FilePersistence — .jsonl 영속화

```csharp
public class FilePersistence
{
    private readonly string _directory;
    private readonly long _maxTotalBytes;      // 기본 5MB
    private readonly string _filePattern = "dataferret_{0}.jsonl";

    public FilePersistence(string basePath = null, long maxTotalBytes = 5L * 1024 * 1024)
    {
        _directory = System.IO.Path.Combine(
            basePath ?? UnityEngine.Application.persistentDataPath,

        _maxTotalBytes = maxTotalBytes;

    }

    // 이벤트 목록을 .jsonl 파일에 append
    public void Save(IEnumerable<EventEnvelope> events) { ... }

    // 모든 .jsonl 파일을 시간순으로 읽어 이벤트 목록 반환
    public List<EventEnvelope> LoadAll() { ... }

    // 성공적으로 전송된 파일 삭제
    public void Delete(string filePath) { ... }

    // 5MB 초과 시 가장 오래된 파일부터 삭제
    private void EnforceMaxSize() { ... }
}
```

**파일 저장 규칙**:
- 저장 경로: `Application.persistentDataPath + "/dataferret/"`
- 파일 포맷: JSON Lines (.jsonl) — 한 줄에 EventEnvelope 1건
- 최대 총 크기: 5MB (초과 시 가장 오래된 파일부터 삭제)
- 파일 이름: `dataferret_{timestamp}.jsonl` (타임스탬프 기반)
- `FileStream`에 명시적 `Flush()` 호출 → 쓰기 완료 보장
- 손상된 파일 (파싱 실패): 해당 줄 스킵 + 경고 로그, 나머지 줄 계속 처리

**오프라인 → 온라인 복구 흐름**:
```
Init() 호출
    │
    ├─ FilePersistence.LoadAll() 호출
    │       → 디렉토리 내 모든 .jsonl 파일 시간순 읽기
    │       → 이벤트 목록 반환
    │
    ├─ EventQueue에 로드된 이벤트 merge (Enqueue)
    │
    └─ 다음 flush 시 Collector API로 재전송
            → 성공 시 해당 .jsonl 파일 삭제
```

### 5.1 ITransport — 인터페이스

```csharp
public interface ITransport
{
    // 이벤트 배치 전송 (비동기, 코루틴 또는 async/await)
    IEnumerator SendBatch(

    );
```

### 5.2 UnityWebRequestTransport — 코루틴 기반 HTTP 전송

```csharp
public class UnityWebRequestTransport : ITransport
{
    private readonly string _endpoint;
    private readonly string _writeKey;
    private readonly int _timeoutSeconds;
    private readonly int _maxRetries;

    public IEnumerator SendBatch(List<EventEnvelope> events, System.Action<bool> onComplete)
    {
        var payload = BuildPayload(events);
        var url = $"{_endpoint}/v1/collect/batch";

        for (int attempt = 0; attempt <= _maxRetries; attempt++)
        {
            // 지수 백오프: 1s → 2s → 4s
            if (attempt > 0)
            {
                yield return new WaitForSecondsRealtime(Mathf.Pow(2f, attempt - 1));
            }

            using var request = new UnityWebRequest(url, "POST");
            var bodyRaw = System.Text.Encoding.UTF8.GetBytes(payload);
            request.uploadHandler = new UploadHandlerRaw(bodyRaw);
            request.downloadHandler = new DownloadHandlerBuffer();
            request.SetRequestHeader("Authorization", $"Bearer {_writeKey}");
            request.SetRequestHeader("Content-Type", "application/json");
            request.timeout = _timeoutSeconds;

            yield return request.SendWebRequest();

            // 성공 (2xx)
            if (request.result == UnityWebRequest.Result.Success)
            {
                onComplete?.Invoke(true);
                yield break;
            }

            // 영구 실패: 재시도하지 않음
            if (request.responseCode == 401 || request.responseCode == 413)
            {
                UnityEngine.Debug.LogError(
                    $"[DataFerret] Permanent failure ({request.responseCode}). " +
                    "Events discarded. Check Write Key.");
                onComplete?.Invoke(false);
                yield break;
            }
        }

        // maxRetries 소진: FilePersistence에 저장
        onComplete?.Invoke(false);
    }

    private string BuildPayload(List<EventEnvelope> events)
    {
        var batch = new BatchPayload
        {
            batch = events,
            sentAt = System.DateTime.UtcNow.ToString("o"),
        };
        return Newtonsoft.Json.JsonConvert.SerializeObject(batch);
    }
}
```

**주의 사항**:
- `UnityWebRequest`는 반드시 Unity 메인 스레드에서 호출 (코루틴으로 처리)
- `request.timeout`은 초 단위 정수 (기본 10초)
- 401 (인증 실패), 413 (페이로드 초과): 재시도 없이 즉시 discard + 에러 로그
- 429 (Rate Limit), 5xx (서버 오류): 지수 백오프 재시도

### 5.3 WebGLTransport — JavaScript Bridge

```csharp
public class WebGLTransport : ITransport
{
    public IEnumerator SendBatch(List<EventEnvelope> events, System.Action<bool> onComplete)
    {
        var payload = BuildPayload(events);
        var url = $"{DataFerretAnalytics.Config.ApiHost}/v1/collect/batch";

        bool completed = false;
        bool success = false;

        WebGLBridge.DataFerret_SendBatch(url, payload, (result) =>
        {
            success = result == 1;
            completed = true;
        });

        yield return new WaitUntil(() => completed);
        onComplete?.Invoke(success);
    }
}
```

**DataFerretBridge.jslib — JavaScript 인터롭**:

```javascript
mergeInto(LibraryManager.library, {
    DataFerret_SendBatch: function(urlPtr, bodyPtr, callbackPtr) {
        var url = UTF8ToString(urlPtr);
        var body = UTF8ToString(bodyPtr);

        fetch(url, {
            method: 'POST',
            headers: {
                'Content-Type': 'application/json'
            },
            body: body,
            keepalive: true  // 페이지 unload 후에도 전송 완료 보장
        }).then(function(response) {
            // 콜백: 1 = 성공, 0 = 실패
            dynCall_vi(callbackPtr, response.ok ? 1 : 0);
        }).catch(function(error) {
            dynCall_vi(callbackPtr, 0);
        });
    },

    DataFerret_SendBeacon: function(urlPtr, bodyPtr) {
        var url = UTF8ToString(urlPtr);
        var body = UTF8ToString(bodyPtr);
        // 페이지 종료 시 최선 노력 전송 (fire-and-forget)
        navigator.sendBeacon(url, new Blob([body], { type: 'application/json' }));
    }
});
```

**WebGL Transport 설계 원칙**:
- `UnityWebRequest`는 WebGL에서 백그라운드 전송 불가 → `.jslib` 브릿지 필수
- `fetch()`의 `keepalive: true` 옵션으로 페이지 이탈 후에도 전송 보장
- `sendBeacon()`은 앱 종료/페이지 이탈 시 fire-and-forget 전송에 사용
- CORS: Write Key의 `allowedOrigins`에 WebGL 게임 호스팅 도메인 등록 필요

### 6.1 FlushScheduler — DontDestroyOnLoad 싱글톤

```csharp
[DisallowMultipleComponent]
public class FlushScheduler : MonoBehaviour
{
    private static FlushScheduler _instance;
    private float _lastFlushTime;

    void Awake()
    {
        // 싱글톤 보장: 중복 인스턴스 즉시 파괴
        if (_instance != null && _instance != this)
        {
            Destroy(gameObject);
            return;
        }
        _instance = this;
        DontDestroyOnLoad(gameObject);
    }

    void Update()
    {
        // 설정된 flushInterval 경과 시 자동 flush
        if (Time.realtimeSinceStartup - _lastFlushTime >= DataFerretAnalytics.Config.FlushIntervalSeconds)
        {
            _lastFlushTime = Time.realtimeSinceStartup;
            DataFerretAnalytics.Flush();
        }
    }

    void OnApplicationPause(bool isPaused)
    {
        if (isPaused)
        {
            // 백그라운드 진입 시 즉시 flush (이벤트 유실 방지)
            DataFerretAnalytics.Flush();
        }
    }

    void OnApplicationQuit()
    {
        // 앱 종료 시 동기 flush (게임 루프 종료 전에 완료)
        DataFerretAnalytics.FlushSync();
    }
}
```

**FlushScheduler 동작 규칙**:
- `Init()` 호출 시 `new GameObject("DataFerretScheduler")`로 생성
- `DontDestroyOnLoad` 적용 — 씬 전환 후에도 유지
- `DisallowMultipleComponent` 속성으로 복수 인스턴스 방지
- `OnApplicationQuit()`: WebGL에서는 JS `sendBeacon` 사용 (async 불가)

### 6.2 SessionTracker — 세션 관리

```csharp
public class SessionTracker
{
    private string _sessionId;
    private float _sessionStartTime;
    private float _backgroundStartTime = -1f;
    private const float SessionTimeoutMinutes = 30f;

    // 세션 시작: Init() 또는 포그라운드 복귀 시
    public void StartSession()
    {
        _sessionId = System.Guid.NewGuid().ToString();
        _sessionStartTime = Time.realtimeSinceStartup;

        DataFerretAnalytics.Track("session_start", new Dictionary<string, object>
        {
            { "session_id", _sessionId },
            { "is_first_session", IsFirstSession() },
            { "days_since_install", GetDaysSinceInstall() },
            { "days_since_last_session", GetDaysSinceLastSession() },
        });
    }

    // 세션 종료: 백그라운드 30분 이상 또는 앱 종료 시
    public void EndSession()
    {
        var duration = Time.realtimeSinceStartup - _sessionStartTime;
        DataFerretAnalytics.Track("session_end", new Dictionary<string, object>
        {
            { "session_id", _sessionId },
            { "duration_seconds", Mathf.RoundToInt(duration) },
        });
    }

    // OnApplicationPause에서 호출
    public void OnPause(bool isPaused)
    {
        if (isPaused)
        {
            _backgroundStartTime = Time.realtimeSinceStartup;
            EndSession();
        }
        else
        {
            // 백그라운드 30분 이상 경과 시 새 세션 시작
            if (_backgroundStartTime >= 0)
            {
                var backgroundDuration = Time.realtimeSinceStartup - _backgroundStartTime;
                if (backgroundDuration >= SessionTimeoutMinutes * 60f)
                {
                    StartSession();
                }
                _backgroundStartTime = -1f;
            }
        }
    }
}
```

**세션 ID 정책**: GUID, 메모리에만 보관 (앱 재시작 시 항상 새 세션)

### 6.5 ErrorTracker — 에러 자동 추적

```csharp
public class ErrorTracker
{
    private readonly Dictionary<string, float> _recentErrors = new();
    private const float DedupWindowSeconds = 60f;

    public void Initialize()
    {
        Application.logMessageReceived += OnLogMessage;
    }

    public void Dispose()
    {
        Application.logMessageReceived -= OnLogMessage;
    }

    private void OnLogMessage(string condition, string stackTrace, LogType type)
    {
        // Exception 및 Error 타입만 추적
        if (type != LogType.Exception && type != LogType.Error) return;

        // 60초 내 동일 메시지 중복 제거
        if (_recentErrors.TryGetValue(condition, out var lastTime))
        {
            if (Time.realtimeSinceStartup - lastTime < DedupWindowSeconds) return;
        }
        _recentErrors[condition] = Time.realtimeSinceStartup;

        DataFerretAnalytics.Track("error_occurred", new Dictionary<string, object>
        {
            { "message", condition },
            // stackTrace를 1000자로 절단 (이벤트 크기 제한 대응)
            { "stack_trace", stackTrace?.Length > 1000
                ? stackTrace[..1000] + "..."
                : stackTrace },
            { "log_type", type.ToString() },
        });
    }
}
```

## 14. 보안 고려사항

| 항목 | 대응 방법 |
|------|-----------|
| **Write Key 바이너리 노출** | Write Key는 쓰기 전용 (읽기/관리 API 접근 불가). 노출되어도 데이터 수집만 가능. 중요 이벤트(결제)는 반드시 Server SDK로 이중 검증 권장 |
| **HTTPS 강제** | `ApiHost`가 `http://`로 시작하면 Init() 시 예외 또는 경고. 모든 전송은 HTTPS |
| **PII 자동 수집 없음** | SDK가 유저 PII를 자동 수집하지 않음. Identify()의 traits는 게임 스튜디오가 직접 선택. 개인정보처리방침에서 명시 필요 |
| **WebGL CORS** | Unity WebGL 빌드는 브라우저 환경이므로 CORS 적용. Write Key 생성 시 `allowedOrigins`에 게임 호스팅 도메인 등록 필요 |
| **IL2CPP Stripping** | Newtonsoft.Json 타입이 IL2CPP 스트리핑으로 제거될 수 있음. `link.xml` 파일로 보존 대상 명시 필요 |
| **PlayerPrefs 평문 저장** | anonymousId, WebGL 큐가 PlayerPrefs에 평문 저장됨. 민감 정보 아님 (익명 ID, 이벤트 내용). 필요 시 AES 암호화 옵션 추가 가능 (Phase 2) |
| **에러 추적 및 PII** | ErrorTracker가 stackTrace를 수집함. stackTrace에 PII가 포함될 수 있으므로 1000자 절단 및 필터링 옵션 고려 |
| **빌드 환경 분리** | BuildProcessor가 Release 빌드에서 `Debug = false` 강제 적용 → 로그를 통한 SDK 내부 정보 노출 방지 |

**link.xml 예시** (IL2CPP Stripping 방지):
```xml
<linker>
  <assembly fullname="Newtonsoft.Json" preserve="all" />
  <assembly fullname="DataFerret.Analytics" preserve="all" />
</linker>
```

```csharp
public class EventEnvelope
{

    // === 식별자 ===
    [Newtonsoft.Json.JsonProperty("anonymousId")]
    public string AnonymousId;                     // 항상 존재

    [Newtonsoft.Json.JsonProperty("userId", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]
    public string UserId;                          // null 허용

    // === 이벤트별 데이터 ===
    [Newtonsoft.Json.JsonProperty("event", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]
    public string Event;                           // track 타입 시 이벤트 이름

    [Newtonsoft.Json.JsonProperty("properties", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]
    public Dictionary<string, object> Properties;

    [Newtonsoft.Json.JsonProperty("traits", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]
    public Dictionary<string, object> Traits;

    [Newtonsoft.Json.JsonProperty("name", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]
    public string Name;                            // page/screen 타입 시 이름

    [Newtonsoft.Json.JsonProperty("groupId", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]
    public string GroupId;

    // === 자동 수집 컨텍스트 ===
    [Newtonsoft.Json.JsonProperty("context")]
    public EventContext Context;

    // === SDK 전송 시간 ===
    [Newtonsoft.Json.JsonProperty("sentAt", NullValueHandling = Newtonsoft.Json.NullValueHandling.Ignore)]

        EventId = null; Type = null; Timestamp = null;
        AnonymousId = null; UserId = null; Event = null;
        Properties = null; Traits = null; Name = null;
        GroupId = null; Context = null; SentAt = null;
    }
```

## 부록 C. Samples~/BasicUsage/SampleTracker.cs

```csharp
using UnityEngine;
using DataFerret.Analytics;
using System.Collections.Generic;

/// <summary>
/// DataFerret Analytics SDK 기본 사용 예시
/// MonoBehaviour에 Attach하여 게임 오브젝트에 추가하세요.
/// </summary>
public class SampleTracker : MonoBehaviour
{
    [Header("DataFerret 설정")]
    [SerializeField] private string writeKey = "wk_proj_YOUR_KEY_HERE";

    void Awake()
    {
        // SDK 초기화 (게임 시작 시 한 번만 호출)
        DataFerretAnalytics.Init(new DataFerretConfig
        {
            WriteKey = writeKey,
            Debug = true,  // 개발 중: 콘솔 로그 활성화
            AutoCapture = new DataFerretConfig.AutoCaptureConfig
            {
                Sessions = true,
                SceneChanges = true,
                Errors = true,
                Lifecycle = true,
            },
        });

        // 글로벌 프로퍼티: 모든 이벤트에 자동 추가
        DataFerretAnalytics.SetGlobalProperties(new Dictionary<string, object>
        {
            { "app_version", Application.version },
        });

        Debug.Log("[Sample] DataFerret Analytics initialized");
    }

    // 버튼 클릭 시 호출
    public void OnPlayButtonClicked()
    {
        DataFerretAnalytics.Track("play_button_clicked", new Dictionary<string, object>
        {
            { "source", "main_menu" },
        });
    }

    // 스테이지 클리어 시 호출
    public void OnStageClear(int stageId, int stars, float timeSpent)
    {
        DataFerretAnalytics.Track("stage_cleared", new Dictionary<string, object>
        {
            { "stage_id", stageId },
            { "stars", stars },
            { "time_spent", timeSpent },
        });
    }

    // 로그인 성공 시 호출
    public void OnLoginSuccess(string userId, int playerLevel)
    {
        DataFerretAnalytics.Identify(userId, new Dictionary<string, object>
        {
            { "level", playerLevel },
        });
    }

    // 로그아웃 시 호출
    public void OnLogout()
    {
        DataFerretAnalytics.Reset();
    }
}
```
